# 🎨 Color Palette Generator

A simple and elegant **Color Palette Generator** built with HTML, CSS, and JavaScript.

Select your favorite color and generate **6 beautiful light-to-dark shades** instantly. Click any color card to copy its HEX code.

---

## ✨ Features

- 🎨 Select any color using the color picker
- 🌈 Generate 6 different shades from light to dark
- 🔢 Display HEX code on every color card
- 📋 Click any color card to copy its HEX code
- ⚡ Instant palette generation
- 🖱️ Interactive hover effects
- 💜 Clean and attractive user interface
